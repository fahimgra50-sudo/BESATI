# বেসাতি (Besati) — রিয়েল ই-কমার্স ওয়েবসাইট

এটি একটি সম্পূর্ণ Next.js + ডেটাবেজ ভিত্তিক অনলাইন শপ। এতে আছে:
- কাস্টমার সাইড: পণ্য ব্রাউজ, কার্ট, ক্যাশ অন ডেলিভারি চেকআউট, অর্ডার ট্র্যাকিং
- এডমিন সাইড: এনক্রিপ্টেড পাসওয়ার্ড লগইন, প্রোডাক্ট ম্যানেজমেন্ট, অর্ডার স্ট্যাটাস আপডেট, সেটিংস
- "স্মার্ট দোকানি" চ্যাটবট: এমনিতেই সাধারণ (rule-based) উত্তর দেয়, চাইলে Anthropic API key দিয়ে আসল AI করে নেওয়া যায়

## 🔧 সর্বশেষ বাগ ফিক্স (এই ভার্সনে)
- **এডমিন প্যানেলে ঢুকলে "destroy is not a function" এরর** — এটার আসল কারণ ছিল `package.json`-এ React ভার্সন (18.2.0) Next.js 14.2.5-এর সাথে বেমানান হয়ে যাওয়া। React ভার্সন 18.3.1-এ আপডেট করে ঠিক করা হয়েছে। **এই আপডেটের পর `npm install` আবার চালাতে হবে।**
- Loyalty Coins-এর হিসাবে ভুল ডিফল্ট মান ছিল (৳100 = 1 Coin হয়ে যাচ্ছিল, ১০ হওয়ার কথা) — schema-তে ঠিক করা হয়েছে।
- **Wishlist** ফিচারের ব্যাকএন্ড কাজ করলেও কোথাও "❤️ যোগ করুন" বাটনই ছিল না — প্রোডাক্ট কার্ড ও প্রোডাক্ট পেজে হার্ট আইকন যোগ করা হয়েছে।
- প্রোডাক্ট পেজে স্টকের সংখ্যা আবার দেখাচ্ছিল (আগে সরানো হয়েছিল) — আবার "In Stock" / "Out of Stock" এ ঠিক করা হয়েছে।

## ১. প্রথমবার নিজের কম্পিউটারে চালানো

### প্রয়োজনীয় জিনিস
- [Node.js](https://nodejs.org) (LTS ভার্সন, ১৮ বা তার বেশি) ইনস্টল থাকতে হবে

### ধাপগুলো
টার্মিনাল খুলে প্রজেক্ট ফোল্ডারে গিয়ে একে একে চালান:

```bash
npm install
cp .env.example .env
```

এরপর `.env` ফাইলটা খুলে `SESSION_SECRET`-এর জায়গায় একটা লম্বা এলোমেলো লেখা দিন (টার্মিনালে `openssl rand -base64 32` চালিয়ে পেতে পারেন)। `ANTHROPIC_API_KEY` খালি রাখলেও চলবে।

```bash
npx prisma migrate dev --name init
npm run seed
npm run dev
```

এখন ব্রাউজারে `http://localhost:3000` খুললে শপ দেখা যাবে।

⚠️ **এডমিন প্যানেল ইচ্ছাকৃতভাবে লুকানো** — সাইটে কোথাও এর লিংক দেখা যাবে না। ঢুকতে হবে সরাসরি এই ঠিকানায়:
`http://localhost:3000/secret-manage-x7k2/login`

**ডিফল্ট এডমিন পাসওয়ার্ড: `admin123`** — লগইন করে সেটিংস থেকে সাথে সাথে বদলে ফেলুন।

এই গোপন ঠিকানাটা (`secret-manage-x7k2`) আরও নিরাপদ রাখতে চাইলে নিজের মতো একটা কঠিন নাম দিয়ে বদলে নিতে পারেন — `src/app/secret-manage-x7k2` ফোল্ডারটার নাম বদলে দিলেই হবে (এবং `src/app/secret-manage-x7k2/login/page.js` ও `dashboard/page.js` ফাইলের ভেতরের পাথগুলোও একই নামে বদলাতে হবে)।

## ২. রিয়েল ডোমেইনে লাইভ করা (হোস্টিং)

⚠️ **জরুরি:** এখন ডেভেলপমেন্টে যে SQLite ডেটাবেজ ব্যবহার হচ্ছে (একটা ফাইল, `dev.db`), সেটা Vercel-এর মতো হোস্টিং-এ স্থায়ীভাবে থাকে না। লাইভ সাইটের জন্য একটা রিয়েল হোস্টেড ডেটাবেজ (PostgreSQL) লাগবে। সহজ পথ নিচে দেওয়া হলো।

### ধাপ ১ — কোড GitHub-এ তুলুন
GitHub-এ একটা নতুন (private) রিপোজিটরি বানিয়ে এই পুরো ফোল্ডারটা পুশ করুন। GitHub অ্যাকাউন্ট না থাকলে বিনামূল্যে github.com-এ একটা বানিয়ে নিন।

### ধাপ ২ — Railway দিয়ে হোস্ট করুন (সবচেয়ে সহজ, নতুনদের জন্য উপযুক্ত)
1. [railway.app](https://railway.app)-এ গিয়ে GitHub দিয়ে সাইন আপ করুন
2. "New Project" → "Deploy from GitHub repo" → আপনার রিপো সিলেক্ট করুন
3. একই প্রজেক্টে "New" → "Database" → "Add PostgreSQL" চাপুন — এটা স্বয়ংক্রিয়ভাবে একটা `DATABASE_URL` তৈরি করে দেবে
4. আপনার ওয়েব সার্ভিসের "Variables" ট্যাবে গিয়ে যোগ করুন:
   - `DATABASE_URL` → PostgreSQL সার্ভিস থেকে কপি করুন
   - `SESSION_SECRET` → একটা লম্বা এলোমেলো লেখা
   - `ANTHROPIC_API_KEY` → (ঐচ্ছিক)
5. `prisma/schema.prisma` ফাইলে `datasource db` ব্লকে `provider = "sqlite"` বদলে `provider = "postgresql"` করে দিন, তারপর আবার GitHub-এ পুশ করুন
6. Railway-এর "Settings" → "Deploy" এ বিল্ড কমান্ড দিন: `npm run build`, এবং একবার শেলে/Deploy hook-এ চালান: `npx prisma migrate deploy && npm run seed`
7. ডিপ্লয় হয়ে গেলে Railway একটা লিংক দেবে (যেমন `bazarwala.up.railway.app`) — এটাই আপনার লাইভ সাইট

### ধাপ ৩ — নিজের ডোমেইন যুক্ত করা
1. Namecheap, Hostinger বা যেকোনো রেজিস্ট্রার থেকে একটা ডোমেইন কিনুন (যেমন `bazarwala.com` বা `bazarwala.com.bd`)
2. Railway-এর প্রজেক্ট সেটিংসে "Custom Domain" এ গিয়ে আপনার ডোমেইনটা যোগ করুন — এটা একটা CNAME রেকর্ড দেখাবে
3. সেই CNAME রেকর্ডটা আপনার ডোমেইন রেজিস্ট্রারের DNS সেটিংসে বসিয়ে দিন
4. কিছুক্ষণ পর (কয়েক মিনিট থেকে কয়েক ঘণ্টা) ডোমেইনে সাইট চালু হয়ে যাবে

*বিকল্প: Vercel + Neon.tech (ফ্রি PostgreSQL) দিয়েও একইভাবে করা যায়, ধাপগুলো প্রায় একই।*

## ২.৫ ড্রপশিপিং অর্ডার ব্যবস্থাপনা
প্রতিটা অর্ডারে (এডমিন প্যানেলের "অর্ডারসমূহ" ট্যাবে) একটা **"সাপ্লায়ারের জন্য কপি করুন"** বাটন আছে। এতে ক্লিক করলে কাস্টমারের নাম, ফোন, ঠিকানা ও পণ্যের তালিকা রেডি টেক্সট হিসেবে ক্লিপবোর্ডে কপি হয়ে যায় — যেটা AliExpress, CJdropshipping বা যেকোনো সাপ্লায়ার সাইটের অর্ডার/শিপিং ফর্মে সরাসরি পেস্ট করা যাবে। যেহেতু আপনি একাধিক প্ল্যাটফর্ম থেকে সোর্স করবেন, প্রতিটার নিজস্ব API আলাদা হওয়ায় পুরোপুরি স্বয়ংক্রিয় সংযোগ সম্ভব নয় — এই পদ্ধতিতে ম্যানুয়াল ধাপ কমে আসবে।

## ২.৬ আসল প্রোডাক্ট ছবি ব্যবহার করা
প্রোডাক্ট যোগ করার সময় এডমিন প্যানেলে একটা "ছবির লিংক" ঘর আছে। যেহেতু এই ওয়েবসাইট নিজে ছবি আপলোড/সংরক্ষণ করে না (ফাইল স্টোরেজ লাগবে, যেটা এখন নেই), তাই ছবি প্রথমে একটা ফ্রি ইমেজ হোস্টিং সাইটে আপলোড করে সেখান থেকে লিংক কপি করতে হবে:

1. [imgbb.com](https://imgbb.com) এ যান (সম্পূর্ণ ফ্রি, অ্যাকাউন্ট ছাড়াই আপলোড করা যায়)
2. dropshipping.com.bd থেকে ডাউনলোড করা পণ্যের ছবি আপলোড করুন
3. আপলোড হওয়ার পর **"Direct link"** নামে একটা লিংক দেখাবে (এটা `.jpg` বা `.png` দিয়ে শেষ হবে) — সেটা কপি করুন
4. এডমিন প্যানেলে প্রোডাক্ট যোগ/এডিট করার সময় "পণ্যের ছবির লিংক" ঘরে সেই লিংকটা পেস্ট করুন

ছবি না দিলে পণ্যটা ইমোজি আইকন দিয়ে দেখানো হবে (যেটা আগে থেকেই কাজ করছিল)।

## ২.৭ লিংক থেকে পণ্যের তথ্য অটো-ফিল
এডমিন প্যানেলে "নতুন প্রোডাক্ট" ফর্মে একটা হলুদ বক্সে dropshipping.com.bd-এর প্রোডাক্ট লিংক পেস্ট করে **"তথ্য আনুন"** চাপলে **নাম, ছবি, বিবরণ ও কোড** নিজে থেকে বসে যাবে।

⚠️ যা এখানে হয় না:
- **ভিডিও** অটো-আনা সম্ভব না
- **আসল পাইকারি/কেনা দাম** আনা সম্ভব না (এটা শুধু তাদের সাইটে লগইন করলেই দেখা যায়) — এটা "পাইকারি দাম" ঘরে আপনাকে নিজে বসাতে হবে, তারপর সিস্টেম স্বয়ংক্রিয়ভাবে **প্রতি পিসে লাভ** দেখিয়ে দেবে

## ২.৮ কাস্টমার অ্যাকাউন্ট
এখন থেকে চেকআউটে কাস্টমারকে একটা ছোট অ্যাকাউন্ট (নাম, ফোন, ইমেইল, পাসওয়ার্ড) বানাতে হবে — একবার বানালে পরের বার থেকে শুধু লগইন করলেই হবে, আবার রেজিস্ট্রেশন লাগবে না। সব নিবন্ধিত গ্রাহকের তালিকা এডমিন প্যানেলে নতুন **"গ্রাহক"** ট্যাবে দেখা যাবে (নাম, ফোন, ইমেইল, ঠিকানা, মোট অর্ডার সংখ্যা সহ)।

⚠️ **এই আপডেটের পর নতুন করে মাইগ্রেশন চালাতে হবে**, নাহলে "Customer" টেবিল ছাড়া এরর আসবে:
```
npx prisma migrate dev --name add_customers
```

## ২.৯ লয়ালটি পয়েন্ট সিস্টেম
প্রতি ১০০ টাকার কেনাকাটায় কাস্টমার ১০ পয়েন্ট পাবে (যেমন ১৫০০ টাকায় ১৫০ পয়েন্ট) — কিন্তু এটা যোগ হয় শুধু **অর্ডার "ডেলিভারি সম্পন্ন" করা হলে** (বাতিল হওয়া অর্ডারে পয়েন্ট যোগ হয় না)। কাস্টমার নিজের পয়েন্ট ও অর্ডার ইতিহাস দেখতে পারবে **"আমার অ্যাকাউন্ট"** পেজে (লগইন করা থাকলে হেডারে লিংক দেখাবে)। কোনো কাস্টমারের পয়েন্ট ৫০০ ছাড়ালে এডমিন প্যানেলের "গ্রাহক" ট্যাবে তার পাশে **"🎁 গিফট প্রাপ্য"** ব্যাজ দেখাবে — এটা শুধু চিহ্নিত করে, গিফট নিজে থেকে পাঠায় না, সেটা আপনি ম্যানুয়ালি ঠিক করবেন।

⚠️ **নতুন করে মাইগ্রেশন লাগবে:**
```
npx prisma migrate dev --name add_points
```

## 🔍 Google সার্চে ভালো অবস্থানে আসার জন্য (SEO)
প্রতিটা প্রোডাক্ট পেজে এখন পণ্যের নাম-দাম অনুযায়ী আলাদা title/description ও Google Rich Snippet ডেটা যোগ হয়েছে, সাথে sitemap.xml ও robots.txt। এটা প্রয়োজনীয় ভিত্তি কাজ করবে, কিন্তু **এটা কোনো গ্যারান্টি না যে আপনার সাইট প্রথম পাতায় আসবে** — Google র‍্যাংকিং নির্ভর করে সময়, প্রতিযোগিতা, ব্যাকলিংক ও কনটেন্টের উপর, যেটা শুধু কোড দিয়ে নিয়ন্ত্রণ করা যায় না।

**লাইভ করার পর এই ধাপগুলো করুন:**
1. `.env`-এ `NEXT_PUBLIC_SITE_URL` আপনার আসল ডোমেইন দিয়ে বসান (যেমন `https://besati.com`)
2. [Google Search Console](https://search.google.com/search-console)-এ গিয়ে আপনার ডোমেইন যোগ করুন, `sitemap.xml`-এর লিংক (`https://yourdomain.com/sitemap.xml`) জমা দিন
3. প্রতিটা পণ্যের নাম ও বিবরণ স্পষ্ট ও বিস্তারিত লিখুন — Google এটা পড়েই বোঝে
4. সাইটের জন্য সামাজিক মাধ্যমে শেয়ার/ব্যাকলিংক তৈরি করুন — এটা র‍্যাংকিং-এ বড় ভূমিকা রাখে

## বেসাতি (Besati) final workflow

### Admin product import
Admin Panel → Products → New Product → paste a product URL from:
- dropgonj.com
- dropshipping.com.bd

Click **তথ্য আনুন**. The server attempts to extract name, image, source price when publicly available, SKU, description, specifications, variants, and source URL. The admin then sets Selling Price, Stock, Category and saves.

> Supplier pages can hide wholesale price behind login or change their HTML. In that case the source price must be entered manually; the system never invents a price.

### Supplier privacy
Supplier URL, supplier price, cost price and internal supplier fields are returned only to authenticated admin requests. Customer-facing product APIs explicitly omit them.

### Loyalty
Delivered orders award Coins using `Settings.coinsPer100` (default 1 Coin per ৳100 subtotal). `Settings.giftCoinsRequired` defaults to 500. Admin selects a Gift Product; the customer can claim it at the required balance.

### Database update
After replacing the project files, run:
`npx prisma db push`
then:
`npx prisma generate`
and start with:
`npm run dev`


## Bangladesh address
Checkout uses 64 districts and 495 upazilas, plus metropolitan thana options where applicable. Thana/Upazila is searchable but selection-only; arbitrary text is rejected server-side.

## Loyalty
Default rule: ৳100 = 10 Coins; 500 Coins = 1 Gift Product.

## 🆕 নতুন যোগ হলো (এই আপডেটে)

### কুপন / ডিসকাউন্ট কোড
এডমিন প্যানেলে নতুন **"কুপন"** ট্যাব — শতাংশ (%) বা টাকা (৳) ছাড়ের কুপন তৈরি করা যাবে, সাথে ঐচ্ছিক সর্বনিম্ন অর্ডার, সর্বোচ্চ ছাড়, মেয়াদ ও ব্যবহারসীমা। কাস্টমার চেকআউট পেজে কোড বসিয়ে "প্রয়োগ করুন" চাপলে সাথে সাথে ছাড় দেখাবে; অর্ডার বসানোর সময় সার্ভার আবার কুপনটি যাচাই করে (মেয়াদ, সীমা, সর্বনিম্ন অর্ডার) — তাই ক্লায়েন্ট সাইড থেকে কেউ ছাড় জাল করতে পারবে না। ⚠️ কোনো নতুন মাইগ্রেশন লাগবে না — `Coupon` টেবিল আগে থেকেই schema-তে ছিল।

### প্রোডাক্ট রিভিউ ও রেটিং
প্রতিটা প্রোডাক্ট পেজে এখন কাস্টমাররা ১-৫ স্টার রেটিং ও মন্তব্য লিখে রিভিউ দিতে পারবেন (লগইন লাগবে)। যে কাস্টমার আগে সেই প্রোডাক্টের কোনো **ডেলিভারি সম্পন্ন** অর্ডার করেছেন, তার রিভিউতে **"✅ ভেরিফাইড ক্রেতা"** ব্যাজ দেখাবে। রিভিউ যোগ/মুছার সাথে সাথে প্রোডাক্টের গড় রেটিং ও রিভিউ সংখ্যা স্বয়ংক্রিয়ভাবে আপডেট হয়ে হোমপেজ ও প্রোডাক্ট কার্ডে দেখা যাবে। ⚠️ কোনো নতুন মাইগ্রেশন লাগবে না — `Review` টেবিল ও `reviewCount` ফিল্ড আগে থেকেই schema-তে ছিল।

### সার্চ ও ফিল্টার
হোমপেজে এখন ক্যাটাগরি ফিল্টারের নিচে "দাম ও সাজানো" বাটনে ক্লিক করলে — সর্বনিম্ন/সর্বোচ্চ দাম দিয়ে ফিল্টার এবং নতুন/দাম (কম-বেশি)/জনপ্রিয়তা (বিক্রি অনুযায়ী)/সর্বোচ্চ রেটিং দিয়ে সাজানো যাবে।

### নিরাপত্তা ফিক্স
প্রোডাক্ট পেজ আগে সার্ভার থেকে পুরো প্রোডাক্ট ডেটা (সাপ্লায়ার লিংক, পাইকারি দাম-সহ) পাঠাচ্ছিল, যেটা যে কেউ পেজ সোর্স দেখলে পেয়ে যেত। এখন শুধু কাস্টমার-facing ফিল্ড পাঠানো হয় — সাপ্লায়ার তথ্য শুধু এডমিন প্যানেলেই দেখা যাবে (README-এর "Supplier privacy" নীতির সাথে মিলিয়ে)।

### পরের ধাপে যা করা যায় (এখনো বাকি)

- **SMS নোটিফিকেশন**: BulkSMSBD-এর মতো লোকাল গেটওয়ে অ্যাকাউন্ট লাগবে
- **অ্যাডভান্সড অ্যানালিটিক্স ড্যাশবোর্ড**: বিক্রি ট্রেন্ড, টপ প্রোডাক্ট, কাস্টমার ইনসাইট ইত্যাদি চার্ট আকারে
